# Indonesian Mahjong — Casual Edition

Versi awal: kalkulator Tay manual berbasis Bandung Mahjong Cup Rulebook ver06.

## Menjalankan
Buka `index.html` di browser modern. Tidak memerlukan instalasi atau server.

## Fitur saat ini
- 44 pola Tay dan nilai Ada Kim / Tanpa Kim.
- Pilih pola secara manual.
- Minimum Hu dapat diubah (default 5 Tay).
- Total dan rincian Tay langsung dihitung.
- Pencarian pola dan salin hasil.

## Batasan yang disengaja
Versi ini belum mendeteksi pola otomatis dari tile, belum menjalankan gameplay, dan belum menyelesaikan aturan overlap/pola khusus yang perlu klarifikasi. Pilihan pola manual tidak berarti hand sudah terbukti memenuhi definisi pola.
